# VOID for Discord Android

VOID is a custom purple theme/mod layer for the **real Discord Android client**. It does not replace Discord with a mock chat app.

## Current build target
- VOID — Purple Night theme (Revenge/Vendetta theme format, spec 2)
- Purple semantic palette and matching raw colors
- Theme import package built by GitHub Actions

## Install concept
This theme requires a compatible Discord Android client-mod loader that supports spec-2/Vendetta themes. The theme JSON alone is **not an APK** and cannot be installed as a standalone app.

## Roadmap
1. Theme and background styling.
2. VOID customization plugin: favorites and friend-color/quick-DM helpers where supported by the client API.
3. Verify support against the exact Discord build from the supplied split APKs before attempting any repackaging.

## Important
- This does not unlock Nitro or override Discord's paid feature restrictions.
- Modified clients can break after Discord updates and may violate Discord's terms. Keep a clean official install available.
- The original Discord APK package is not committed to this public repository.
