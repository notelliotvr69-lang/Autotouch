Phone companion + Quest spatial client prototype · Rootless by design

One launcher. Separate controls for each game.

VRFlex is a Quest launcher and profile manager. The intended controller layout is simple: left Y opens the Mod Menu, while the left Menu (☰) opens the Games switcher. The Games screen lets you select an installed app, save its profile, and launch it.

VRFlex menus

Mod Menu · Left Y

The intended shortcut for the active game's profile settings, including movement, comfort, and arm preferences.

Games · Left Menu (☰)

Browse installed apps, choose another game, and launch it from the switcher. VRFlex saves the selected game profile before launching.

Automatic profile selection

Launching an app through VRFlex makes that app the active profile. The same profile values are shown in the Games and Mod Menu screens.

Rootless by design

No root, bootloader unlocking, firmware flashing, protected partition writes, system APK replacement, or hidden shell commands.

Honest capability status

Current spatial prototype: immersive 3D scene, black-and-orange styling, a spatial menu with Games / Mod Menu / Arms sections, game-launch actions, and preview sliders.

Prototype limitations: the Quest APK is currently a standalone immersive launcher panel, and the phone APK currently provides ADB wireless pairing and device diagnostics. Phone-hosted game execution, live phone-to-Quest video/audio streaming, Quest tracking return, finger-pointer selection, persistent overlays over other games, and actual cross-game arm-length changes are not implemented yet. Sliders currently change saved preview/settings values only; both APKs still need real-device testing.

VRFlex is an independent project within the AutoTouch repository. Not affiliated with or endorsed by Meta.
