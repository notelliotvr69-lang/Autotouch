Quest OS panel launch

New: VRFlex now declares Meta Horizon OS's documented 2D overlay-launch activity category. On supported Horizon OS versions (v69+), you can launch the VRFlex panel from the Quest app/overlay launch flow while an immersive app is running.

This is an OS-managed panel, not a custom always-on-top Android window. The operating system controls when it opens and where it is placed.

What works now

App library

Browse launcher-visible apps on the headset and keep separate VRFlex profiles.

Profile controls

Store sitting preference, movement values, and arm settings locally per selected game. These values need a compatible game adapter to affect gameplay.

OS overlay launch

The app manifest includes Meta's documented OVERLAY_LAUNCHER category for a 2D panel launched over an immersive app on supported Horizon OS versions.

Wireless companion

Connect an Android phone and Quest over the same Wi-Fi network using the headset's local IP. No USB ADB workflow.

Downloads

Install the latest published VRFlex APK on your Quest. The release is updated by the repository's APK build workflow.

What the OS does not expose to this app

Hold Y to summon VRFlex at any time and pin it to the left controller are not available through the documented public panel-launch API. The OS overlay-launch category allows a user-initiated panel launch; it does not grant global controller-button interception, left-hand anchoring, or universal tracking modification. A hold-Y shortcut and hand-following panel therefore remain unimplemented. Those behaviors would need an official system API or cooperation from each game's integration.

VRFlex does not use root, bootloader changes, firmware flashing, protected system writes, or replacement of Horizon OS files.
