VRFlex

Standalone Quest VR developer environment · Rootless by design

A standalone VR app with a controller-attached menu.

VRFlex is being rebuilt as an immersive OpenXR app for Quest. The intended interface is a 3D menu attached to the left controller, shown while the Y button is held. It does not require a phone companion.

VR menu modules

Controller menu

Planned OpenXR panel anchored to the left controller and shown while Y is held. The native VR input and rendering layer is being built.

Profiles

Keep independent local settings profiles for supported games. Saved values only affect gameplay when a compatible integration consumes them.

Movement & controller tools

VRFlex can control its own OpenXR session. Changes to another game require a compatible game-side integration.

Rootless by design

No root, bootloader unlocking, firmware flashing, protected partition writes, system APK replacement, or hidden shell commands.

Downloads

Install the latest published builds. APK links update when their GitHub Actions workflows finish successfully.

Honest capability status

Project direction: standalone immersive OpenXR app with a left-controller menu, opened while Y is held, and locally stored profiles.

Current status: the published APK is still the earlier 2D prototype. The native OpenXR app, controller-attached menu, and hold-Y behavior are not implemented or hardware-tested yet. OpenXR input and tracking operate within VRFlex itself; live changes to other games require compatible integrations.

VRFlex is an independent project within the AutoTouch repository. Not affiliated with or endorsed by Meta.
