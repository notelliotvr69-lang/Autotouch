Use it

  1. Run QuestLinkPC.exe on the PC. It shows the PC's LAN IP.
  2. Open QuestLink on the headset and enter that IP.
  3. Press Connect to PC.
  4. The Quest app loads detected Steam PCVR games plus supported Meta Horizon PC-library apps.
  5. Tap a game to launch it. Gorilla Tag uses Quest Link + SteamVR/OpenVR, and the Quest app can remotely apply SteamVR world/render-scale settings.

Important

The IP connection controls the PC companion only. It does not install APKs or other software over the network.
