Current flow

  1. Install and activate the QuestLink OpenXR runtime on the PC.
  2. Run the QuestLink PC app and note the LAN IP it shows.
  3. Install/open the Quest APK and enter that PC IP.
  4. The Quest launcher loads runtime status, PCVR games, and Gorilla Tag mod/plugin details.
  5. Launch Gorilla Tag with QuestLink or launch another detected PCVR title from the headset.

Streaming status

The launcher/control path is being built now. The actual PC-rendered VR video stream plus live Quest head/controller tracking bridge is still the next major client/runtime milestone.

Heads up

QuestLink V0.2 is still a prototype runtime. The website does not claim full Virtual Desktop-style streaming is finished yet. The goal is the same flow, but the video encoder/decoder and live tracking transport still need to be connected.
