Current flow

  1. Install and activate the QuestLink OpenXR runtime on the PC.
  2. Run QuestLink PC V7.11 and note the LAN IP it shows.
  3. Install/open Quest V7.11 and enter that PC IP.
  4. The Quest launcher loads runtime status, PCVR games, and Gorilla Tag mod/plugin details.
  5. Launch Gorilla Tag with QuestLink. PC V7.11 swaps GTAG to the bundled OpenComposite bridge, then starts it with -vrmode openvr. SteamVR is not started.

Streaming status

The current GTAG test path is: Gorilla Tag OpenVR → bundled OpenComposite → QuestLink OpenXR runtime → Quest V7.11. SteamVR is not part of this path. The stream is still a prototype preview bridge, not final Virtual Desktop-quality streaming.

Heads up

QuestLink is still a prototype. The no-SteamVR GTAG bridge is now packaged, but full low-latency immersive streaming, controller tracking, hardware H.264/H.265 encoding, and final compositor integration are not finished yet.
