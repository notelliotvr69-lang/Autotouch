Install

  1. Open this page in the Quest browser.
  2. Press Download QuestLink APK.
  3. Open the downloaded APK and approve the install prompt.
  4. Launch QuestLink Client and pair it with the QuestLink PC app.

What the headset app is for

The Quest app is the headset-side control center for the VR / PCVR library, pairing, game-mode selection, and PCVR controls. The Windows app handles the PC-side Steam/runtime work.
