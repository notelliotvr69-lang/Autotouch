# CHAI Lite

An independent, original Android character-chat platform prototype.

## Current milestone
- Native Android app using Kotlin and Jetpack Compose.
- Initial dark chat interface.
- GitHub Actions workflow builds a debug APK.
- No CHAI code, private APIs, or proprietary assets are used.

The current chat screen is a UI prototype. It does not yet include an AI model, accounts, cloud sync, public bot discovery, moderation tools, or CHAI conversation import. Those features will be developed separately and transparently.

## Build
Run the Build CHAI Lite Android workflow from the Actions tab, then download the chai-lite-debug-apk artifact.
